# Незавершённая оплата

13.10.2026 сохранён HTML-reference ошибки оплаты: пример timeout подтверждения/3D Secure, выбор метода и повторное действие. Это дизайн-пример, не интеграция PSP.

Перед повтором сервер выясняет исход предыдущей попытки. Timeout сам по себе не означает, что деньги не списаны. Повтор связывается с тем же заказом и защищается идемпотентностью; новая попытка допустима по подтверждённому состоянию provider. Точная причина, суммы, методы и обещания показываются из реальных данных, не фиксируются из макета.
