# Первая страница корзины

13.10.2026 пользователь передал reference.html как пример первой страницы корзины. Исходник сохранён без изменений; это дизайн-reference, не реализованный checkout.

При переносе строки корзины связаны с конкретными SKU/цветами/размерами. Количество, доступность, цены, скидки и итог рассчитываются/проверяются сервером. Значения, доставка и коммерческие обещания из примера не становятся условиями магазина автоматически. Внешние зависимости заменяются проектными styles/assets.

Следующие этапы оформления, данные покупателя, доставка и оплата — отдельные экраны и контракты; этот reference их не утверждает.
