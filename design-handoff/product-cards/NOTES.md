# Выбранная основа мини-карточек

13.10.2026 пользователь выбрал мини-карточки из присланного HTML как основу. Извлечена секция CuratedProducts с четырьмя карточками и связанными toast/quick-view элементами.

- preview.html — отдельный preview с исходными CSS/CDN dependencies.
- cards-fragment.html — точный фрагмент секции, включая её inline script.
- interactions.js — те же функции отдельно для изучения; не подключать одновременно с inline script, чтобы не дублировать логику.
- source.html — исходная страница без изменений.

Пример даёт фото, бренд/название, цену, цвета, размеры, обозначение наличия, quick view, wishlist и кнопку корзины. Это визуальная основа, не готовая торговая логика.

При переносе в Django:

- Цвет сейчас меняет выделение и подпись, но не фото; подключить галерею реального варианта.
- Размер/остаток представлены демо-значениями, не согласованной матрицей цвет×размер. Подключить общий variant contract со страницей товара.
- quickAddToCart только имитирует успех через setTimeout, не добавляет выбранный SKU. До реализации корзины явно сохранять demo-состояние, не выдавать за успешную покупку.
- Внешний Tailwind, Google Fonts и image URLs принадлежат исходному reference, не утверждённому production runtime; стили и assets переносить в локальную систему.
- Проверить touch targets, keyboard radio navigation, focus/escape modal и доступность quick-view без hover.

Текущая главная не заменена этим reference. Перенос в компоненты — отдельный этап.
