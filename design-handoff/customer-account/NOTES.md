# Кабинет покупателя

13.10.2026 получены пять документов: mobile overview, desktop empty orders, order detail, combined profile/addresses/security/marketing и desktop overview. Разделены по файлам; оригинал сохранён.

Клиентский кабинет следует стилю сайта. Staff/admin кабинет использует codex-django cabinet, этим reference не заменяется. Встречающееся Atelier Salon — постороннее название генератора, при переносе заменить на рабочий бренд Männermasche. Данные покупателя, tracking и условия доставки — demo.

Mobile деталей заказа/профиля и отдельный список непустых заказов не считаются полученными только по наличию обзора. Адаптацию проверяем при сборке. Реальные операции требуют object permissions, безопасной смены пароля и актуальных consent/suppression правил рассылки.
