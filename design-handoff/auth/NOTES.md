# Авторизация: комплект макетов

13.10.2026 объединённый файл разделён на пять HTML-документов: desktop register/login/reset, mobile login и combined register/reset. Исходник сохранён в source-combined.html. Это visual references, не реализованный auth flow.

На этой основе достраиваем состояния запроса reset, нейтрального подтверждения отправки, ввода нового пароля, успешной смены, неверной/истёкшей ссылки; также email verification и смену пароля в кабинете при необходимости. Отдельная генерация каждого состояния не обязательна.

Использовать штатные Django auth forms/views/tokens там, где они соответствуют сценарию, существующие библиотечные механизмы после проверки. Регистрация/email verification не считаются готовыми возможностями Django auth автоматически. Не раскрывать существование аккаунта в reset-ответе; не объединять рекламный opt-in с регистрацией. Без реальной отправки писем в статическом прототипе.
