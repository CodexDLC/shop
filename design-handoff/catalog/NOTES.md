# Каталог: комплект примеров

Получены 13.10.2026:

- desktop-01.html — обычная выдача с фильтрами.
- desktop-02.html — нулевая выдача после фильтрации.
- mobile.html — мобильный пример, горизонтальный ряд с карточками 82vw и видимым продолжением, активные фильтры.

Исходники сохранены без изменения. Получение примеров не подтверждает рабочую фильтрацию, смену фото цвета и соответствие всех состояний требованиям. Точную ширину карточек и snap поведение проверим при переносе; 82vw — настройка reference, не обязательный контракт. Переключение отдельных фотографий остаётся открытым решением.

Перед переносом согласовать единую палитру/шрифты между вариантами, заменить CDN локальными ресурсами, подключить общий variant contract. Сайт пока не изменён этим комплектом.
