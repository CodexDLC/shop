# Männermasche — подготовка магазина

Интерактивная HTML-демонстрация: [docs/prototype](docs/prototype/README.md), вход [docs/index.html](docs/index.html). Отдельный статический прототип для будущего GitHub Pages, не production-магазин.

Собрана основа: Django web, независимый Python-движок и отдельный ARQ worker. Commerce-функции пока не реализованы, реальные оплаты и запись eBay отсутствуют. [Установка и запуск](docs/project/foundation-run.md).

Начать здесь: [документация проекта](docs/README.md), [план разработки](docs/project/roadmap.md), [открытые решения](docs/project/open-questions.md).

- [Предварительный стек](docs/предварительный-стек/README.md): Django, внешние сервисы, границы модулей.
- [Внешние API](docs/предварительный-стек/external-api.md): кандидаты и условия подключения.
- [Datenschutz](docs/предварительный-стек/datenschutz.md): юридические тексты, согласия и работа с данными.
- [Анализ рынка](analysis/README.md): сборщик подсказок, выгрузки, исследования конкурентов и доменов.
- `assets/hero/`: сохранённый исходник для hero.

Временные дубликаты двух CSV в корневой `data/` удерживаются открытым приложением. Проверенные копии находятся в `analysis/data/`; рабочая папка данных теперь там.
