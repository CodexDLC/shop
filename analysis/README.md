# Подсказки для мужского белья

Небольшой сборщик на Python 3.10+ без внешних библиотек и API-ключей. Сохраняет реальные ответы Google autocomplete, а не придуманную частотность.

Запуск из этой папки:

```powershell
python collector.py
python collector.py --expand --max-requests 20
python collector.py --export-only
python -m unittest discover -s tests -v
```

Начальные фразы находятся в `seeds.txt`, по одной на строку. Обычный запуск проверяет пять фраз; `--expand` добавляет слова и буквы к каждой фразе, последовательно в порядке файла. Поэтому небольшой лимит может покрыть только первый бренд. Для отдельного бренда создайте свой файл и передайте `--seeds my_seeds.txt`.

Результат: `data/queries.sqlite3` и `data/suggestions.csv`. CSV использует UTF-8 с BOM и разделитель `;` для Excel. Одна строка — наблюдение подсказки с исходным запросом, рангом и датой UTC; одна подсказка может иметь несколько источников. Уникальные фразы хранятся отдельно в базе. Ошибки и запуски также сохраняются.

Успешные запросы повторно не отправляются. Для обновления используйте `--refresh`. Доступны `--data-dir`, `--delay` (не меньше секунды), `--timeout`, `--max-requests` (по умолчанию 20). Лимит считает только новые сетевые обращения, а не кешированные запросы. При ошибке, включая HTTP 403/429 или неожиданный формат, сбор останавливается без обхода блокировок; выполненная часть сохраняется, код завершения — 1.

Ограничения: публичный endpoint не является гарантированным API; доступность может меняться. Параметры `hl=de` и `gl=de` запрашивают немецкие подсказки и страну DE, но не доказывают географию аудитории и не исключают влияние местоположения сервера. Подсказка не доказывает низкую частотность, наличие покупателей или возможность занять место конкурента. Частотность, SEO-конкуренция и прогноз продаж не рассчитываются. Серии M800 и RED1201 — исходные фразы для проверки, не подтверждение вашего наличия. Сбор конкурентной выдачи в эту версию не входит.
