# Сравнение оплаты для магазина DE

Проверено 15.10.2026 по публичным источникам. Владелец выбрал **Stripe Checkout hosted + PayPal через Stripe, один платёжный API, сначала sandbox**. Сравнение альтернатив сохранено для оценки стоимости; это не live-активация и не индивидуальный договор. Рынок DE, расчёты EUR; Klarna рассматриваем отдельно.

## Короткий список

| Вариант | Применимость к нашему магазину | Ограничение/следующая проверка |
|---|---|---|
| Stripe Checkout, карты + PayPal | Один основной адаптер, hosted checkout; официальный Python SDK; полные/частичные refunds, sandbox | Подтвердить активацию PayPal для DE-аккаунта, его тариф и правила settlement |
| Mollie hosted checkout, карты + PayPal | Один PSP-адаптер; официальный Python SDK; PayPal и немецкие методы | PayPal имеет собственную комиссию плюс надбавку Mollie; уточнить стоимость всех refunds |
| PayPal напрямую; при необходимости Stripe для карт | Контроль прямой PayPal-интеграции, API refunds и sandbox | Два адаптера/набора webhooks и сверок при добавлении Stripe; дополнительные затраты разработки ради небольшой экономии |

Официальные технические источники: [Stripe SDK](https://docs.stripe.com/sdks), [Stripe PayPal: DE, Checkout, полные и частичные возвраты](https://docs.stripe.com/payments/paypal), [Mollie официальный Python SDK](https://github.com/mollie/mollie-api-py), [PayPal refunds API](https://developer.paypal.com/api/payments/v2/captures-refund).

Для Django подходят все три. Не требуется специальный Django-плагин: PSP SDK/HTTP находится в адаптере вне движка; Django управляет заказами, правами и webhooks; ARQ выполняет фоновые операции через независимые контракты. У Mollie использовать `mollie-api-py`, не путать с legacy/community `mollie-api-python`. Версию SDK и совместимость проверим перед установкой.

## Пример стоимости одной успешной оплаты

Условные чеки, не фактические показатели магазина. База — вся оплачиваемая сумма, включая доставку, если она включена в платёж. Округление до цента на транзакцию; фактические правила PSP могут отличаться.

| Оплачено | Stripe, стандартная карта ЕЭЗ | Mollie, потребительская карта ЕЭЗ | PayPal напрямую по указанной ставке | PayPal через Mollie | PayPal через Stripe |
|---|---:|---:|---:|---:|---:|
| 35 € | 0,78 € | 0,88 € | 1,40 € | 1,50 € | 1,57 € |
| 55 € | 1,08 € | 1,24 € | 1,99 € | 2,09 € | 2,20 € |
| 85 € | 1,53 € | 1,78 € | 2,89 € | 2,99 € | 3,16 € |

Для PayPal во всех вариантах взят один базовый тариф PayPal Checkout DE. Индивидуальная ставка, FX и иные условия меняют результат. Надбавка Stripe на чеках 35/55/85 € составляет 0,17/0,21/0,27 €; при 100 PayPal-платежах по 55 € — 21 € за единую интеграцию относительно прямого PayPal.

При 100 оплатах по 55 € все картой: около 108 € Stripe против 124 € Mollie. Доплата 0,10 € за PayPal через Mollie — 10 € на 100 PayPal-платежей. Это расчёт оплаты без возвратов/споров, не оценка прибыли и не обещание экономии на всём магазине. Не стоит усложнять интеграцию ради такой суммы без оценки обслуживания второго адаптера.

## Возмещения и денежный остаток

- Stripe сообщает, что комиссии обработки исходного платежа при refund не возвращаются; возможные отдельные комиссии зависят от тарифного плана. [Правило Stripe](https://support.stripe.com/questions/understanding-fees-for-refunded-payments).
- Mollie указывает 0,25 € за refund в разделе о PayPal. Универсальность этого тарифа для карт/Klarna и судьбу исходной комиссии необходимо подтвердить по конкретному договору, не распространять правило молча на все методы. Для PayPal нужен достаточный PayPal-баланс. [Mollie refunds](https://help.mollie.com/hc/en-us/articles/115000014489-How-do-I-refund-a-payment).
- Немецкая таблица PayPal описывает удержание фиксированной части при возврате. Итог по конкретному PayPal-продукту и маршруту через PSP нужно подтвердить; нельзя автоматически переносить условия США. [PayPal DE, раздел Rückabwicklung geschäftlicher Transaktionen](https://www.paypal.com/de/business/paypal-business-fees).
- Возврат по API не означает моментального зачисления покупателю. Учитываем pending/failed, доступный баланс, сроки, частичные операции и журнал подтверждения сотрудником. Необходимы тесты всего пути в sandbox.

## Что подтвердить до выбора

Для каждого кандидата: юридическое лицо DE и одобрение фактического ассортимента/витрины; доступность PayPal и карт; полная смета комиссии за оплату, частичные refunds и chargebacks; сохранение первоначальной комиссии; payout schedule, первый payout, резервы/удержания и минимальный остаток; источник денег на refunds; подтверждение/отмена операций, идемпотентность и квоты; выгрузка выплат, комиссий и reconciliation для бухгалтерии. Не обещаем сроки выплаты без проверки аккаунта. Одобрение стандартного белья не переносим автоматически на любую будущую категорию/визуальный контент.

## Сравнение с eBay

Официальный тариф eBay.de для коммерческих продавцов в категории Kleidung & Accessoires (#11450), проверен 15.10.2026: 12% до 990 € и 3% с превышения; фиксированный сбор 0,45 € за заказ свыше 10 € (иначе 0,35 €). База — вся сумма продажи, включая оплаченный покупателем Versand и НДС товара. Обработка платежа входит в комиссию: отдельную комиссию PayPal поверх неё не добавляем. Тарифы eBay опубликованы без НДС на услуги. Это стандартный сценарий при соответствующей категории и статусе продавца, не подтверждение индивидуального счёта магазина. [Тарифы eBay](https://www.ebay.de/help/selling/fees-credits-invoices/gebuehren-fuer-gewerbliche-verkaeufer?id=4809).

Реклама Basis: установленная продавцом ставка применяется к продаже, соответствующей правилам атрибуции. Сценарий 10% ниже — выбранная ставка, не обязательная комиссия. Текущие правила описывают покупку рекламируемого товара после клика любого покупателя по его рекламе за последние 30 дней, при рекламе в моменты клика и продажи. Premium оплачивается за клики, поэтому модель «ещё 10%» на него не переносится. [Атрибуция рекламы](https://pages.ebay.de/anzeigen/zuordnung/).

### Заказ на 55 €: сколько остаётся после комиссий

Одинаковая оплаченная сумма 55 €, без возврата. Ставки PSP взяты из таблицы выше, округление на уровне операции. Из остатка ещё НЕ вычтены закупка, НДС с продажи, фактическая доставка/упаковка, инфраструктура, обслуживание и реклама сайта. Остаток не является прибылью. НДС на комиссии, подписка eBay, платные размещения, международные/дополнительные сборы и индивидуальные скидки здесь также не учтены; налоговый учёт сверяется с бухгалтером и выпиской. [НДС на услуги eBay](https://www.ebay.de/help/selling/fees-credits-invoices/umsatzsteuer-auf-ebaygebhren-fr-verkufer-und-nutzer-aus-deutschland?id=4837).

| Канал и оплата | Комиссии | Остаток от 55 € | Разница с eBay без рекламы | Разница с eBay и рекламой 10% |
|---|---:|---:|---:|---:|
| eBay без рекламы: 55 × 12% + 0,45 | 7,05 € | 47,95 € | — | — |
| eBay с начисленной Basis-рекламой 10%: 7,05 + 5,50 | 12,55 € | 42,45 € | — | — |
| Сайт: Stripe, стандартная карта ЕЭЗ | 1,08 € | 53,92 € | +5,97 € | +11,47 € |
| Сайт: PayPal через Stripe при указанном тарифе PayPal | 2,20 € | 52,80 € | +4,85 € | +10,35 € |
| Сайт: Mollie, потребительская карта ЕЭЗ | 1,24 € | 53,76 € | +5,81 € | +11,31 € |
| Сайт: PayPal Checkout напрямую | 1,99 € | 53,01 € | +5,06 € | +10,56 € |
| Сайт: PayPal через Mollie по той же ставке PayPal | 2,09 € | 52,91 € | +4,96 € | +10,46 € |

Расчёт выполнен Decimal с ROUND_HALF_UP до цента. Фактическое округление провайдера и индивидуальные тарифы проверяются при интеграции. Выбранная связка Stripe оставляет 52,80–53,92 € в зависимости от метода из приведённых стандартных ставок.

### Возможность акций и собственного привлечения

Для выбранной связки Stripe разница около 4,85–5,97 € относительно органической продажи eBay либо 10,35–11,47 € относительно продажи с Basis-рекламой 10% даёт предварительный финансовый резерв на заказ. Его можно распределять между скидкой, привлечением и обслуживанием сайта, но не считать одновременно полной прибылью и полным рекламным бюджетом.

При одинаковом чеке предельный добавочный бюджет привлечения для сохранения сопоставимого остатка = экономия комиссий − дополнительные расходы сайта на заказ. Если даём скидку, пересчитываем выручку и комиссию PSP от сниженного чека; не сравниваем её как прежние 55 €. Для Google Ads считаем стоимость приобретённого оплаченного заказа (CAC/CPA), а не только клика; учитываем отмены и возвраты. Выгодность или объём трафика Google этим расчётом не доказаны.

Маркетплейс также приводит покупателей; сайт оплачивает собственный трафик и инфраструктуру. Для фактической оценки нужны выписка магазина, доля рекламных продаж, реальные чеки и возвраты. Раннее предположение «20% + 10%» заменено проверенным стандартным сценарием выше; его нельзя продолжать использовать как подтверждённую базовую ставку.

Расчёт: экономия комиссий = удержания eBay по сопоставимым заказам − расходы PSP. Финансовый результат собственного канала дополнительно учитывает рекламу/CAC, хостинг, обслуживание, fraud/disputes, возвраты и доставку. Первоначальные и невозвращаемые комиссии учитываются даже по возвращённым заказам.

## Предварительный вывод

**Выбрано: Stripe Checkout hosted + PayPal через Stripe, сначала sandbox.** Приоритет — проверенный единый API и меньший объём собственного платёжного кода. Доплата за PayPal принята как стоимость интеграции, а не объявлена экономией. Live-доступ методов, индивидуальные условия refunds, settlement и выплаты проверяются перед отдельной активацией. Mollie и прямой PayPal остаются альтернативами для будущего пересмотра; сейчас второй адаптер не делаем.
