# Открытые решения

Не мешают начать локальный каталог на тестовых данных, но нужны перед соответствующими интеграциями.

| Вопрос | Когда нужен |
|---|---|
| Источник начального каталога: eBay, таблица или ручной ввод; названия, описания и цены | Перед импортом каталога |
| Кто выбирает главное фото/порядок; начальный вариант карточки и показ недоступных вариантов | Перед приёмкой карточки |
| Образец структуры папок/имён фото; артикул и код цвета | Перед автоматическим импортом |
| Выгрузка eBay: item ID, SKU, EAN, вариации и доступное количество | Перед сопоставлением и stock sync |
| Один физический запас или отдельные запасы у listings одного SKU | Перед расчётом количества |
| Где основной учёт; кто и где вручную меняет остаток | Перед двусторонней синхронизацией |
| Когда резервировать сайт: оформление/оплата; срок резерва, отмены | Перед checkout |
| eBay developer app, OAuth-доступ, методы и фактические квоты | Перед live чтением/записью |
| Размерные обозначения брендов, группировка коллекций/моделей | Перед полноценным каталогом |
| Цена с учётом налогов, доставки, скидок; возможность предзаказа | Перед реальным checkout |
| Stripe Checkout + PayPal через Stripe выбраны: создать sandbox; перед live подтвердить DE-аккаунт, PayPal Business, активацию методов, settlement, комиссии и выплаты | Sandbox — до реализации; live — отдельное решение |
| Прямая интеграция DHL выбрана: подтвердить договор, доступ Shipping/Pickup/Tracking/Returns API, расчётные реквизиты, адрес, даты/сроки и стоимость группового забора; квоты/Push и события приёма посылки; receiverId, стоимость возвратов и юридические сроки возмещения | Перед shipping adapter |
| Бухгалтерская программа и формат документов | Перед счетами/учётом |
| Домен, юридический пакет и фактические внешние сервисы | Перед публичным запуском |

Не требуется заранее: доступ ко всем 30 ГБ фотографий, оплата всех подписок, настройка двух серверов, окончательное выделение библиотеки.
