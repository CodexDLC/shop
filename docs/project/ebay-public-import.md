# Публичный импорт eBay — подготовка

## Проверка 15.10.2026

Источник: публичный каталог продавца `sonne_fuer_alle`, магазин https://www.ebay.de/str/sonnefuralle.

Запрос `https://www.ebay.de/sch/i.html?_ssn=sonne_fuer_alle` из разрешённого сетевого окружения вернул HTTP 403 Forbidden. Сбор остановлен. Обход блокировки, использование cookies сотрудника и повторный массовый обход не выполнялись. Новые товары и фотографии этой попыткой не импортированы; текущие демонстрационные позиции не являются результатом этого сбора.

Продолжить через одобренный eBay API, выгрузку владельца либо предоставленные сохранённые страницы. Не подменять отсутствующие размеры, цены, фотографии и остатки выдуманными значениями.

## Согласованная структура каталога

- Одна модель/артикул производителя и один фасон — Product. Совпадения серии недостаточно для объединения разных фасонов.
- Цвет + размер — ProductVariant с собственным SKU, ценой и доступностью. Отдельные объявления eBay связываются с вариантом отдельными channel bindings; идентификатор объявления не заменяет SKU.
- Выбор цвета меняет набор реальных фотографий этого цвета. Размеры одного цвета используют его галерею. Не перекрашивать фото и не выдавать общую фотографию за подтверждённое фото другого цвета.
- Выбор размера определяет конкретный вариант. Недоступные сочетания не разрешают оформление заказа.
- Не суммировать остатки разных объявлений без подтверждения, что они относятся к разным физическим запасам. Публичные данные — снимок, а не синхронизация запасов.

## Проверяемый импорт

Сначала сохранять исходное объявление, URL, время получения, валюту, цену и её контекст (фиксированная, от, диапазон), явно найденные размеры/цвета и ссылки на фото. Отдельно хранить предполагаемую группировку и причины сомнений. Список вариантов в селекторе не доказывает наличие каждого сочетания. Объединение по неоднозначному названию требует проверки.

## Страницы и поиск

Покупатель видит одну карточку с переключателями цвета и размера. Основная страница модели имеет стабильный URL. Параметры выбранного варианта могут сохраняться в URL для ссылки на конкретный вариант. Отдельные индексируемые страницы цвета допустимы после отдельного SEO-решения при самостоятельном содержании; не создавать автоматически страницы каждого размера или дубли из каждого объявления eBay.

Документ фиксирует требования и результат проверки. Channel bindings, импорт и вариантные SEO-страницы этой попыткой не реализованы.
