## Журнал выполнения

- Выполнены пункты 1–4. `catalog_products()` — ограниченный lazy queryset, AND-фильтры + поиск, четыре SQL на непустую страницу. Неактивные варианты не участвуют в выдаче/поиске.
- `codex_ecommerce.catalog` — immutable Variant/Gallery/VariantSelection, точный выбор, ошибки неоднозначности/валюты. Движок не содержит ORM или framework imports. Это проверка снимка, не резерв и не разрешение финансовой операции.
- `web.catalog.adapters.CatalogVariantSelection` — ORM adapter, три SQL на продукт/варианты/галереи, без записей.
- Маршрут `catalog:variant_preview`: GET `/produkt/<slug>/variante/?color=black&size=M`. JSON всегда содержит `mode=demo`, `checkout_enabled=false`; доступность называется `demo_available`. POST 405; ответы no-store/noindex. Ожидаемые ошибки переведены ключами немецкого каталога.
- Проверки: 101 pytest, Ruff, Django check, makemigrations --check — успешно. Полный pytest в Windows выполнен вне ограниченного sandbox из-за зависания subprocess-проверки внутри sandbox.
- Дополнительный сервер 8031 проверен HTTP-запросами на локальном PostgreSQL: главная 200, M 200 доступен в demo, XL 200 недоступен, XXXL 404 с понятным сообщением. Основной сервер 8030 не перезапускался. Изменения внешнего вида не вносились.
- Аналитика этапа: новые cookies, рекламные SDK и события не добавлялись; endpoint не сохраняет запросы в бизнес-таблицы. Обычные dev access logs остаются локальными; production retention/access logging потребуют настройки перед публикацией.
- 16.10.2026 выполнена привязка главной/PDP к ORM: 106 pytest, Ruff/Django check/migrations успешно. Браузер desktop/mobile: SKU, недоступный XL, цвет, переходы, modal, сетевой отказ и stale response guard проверены. Подробности в catalog-read-api.md.
