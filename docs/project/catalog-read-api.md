# Read-only каталог и варианты

Основа реализована 15.10.2026, главная и PDP подключены к ORM 16.10.2026. Внешний вид согласованного прототипа сохранён; остальные экраны каталога и нижние редакционные/рекомендательные блоки пока используют явно отмеченные presentation-моки.

## Выборка

`web.catalog.selectors.catalog_products(query='', category='', brand='', tag='', limit=24, offset=0)` возвращает ленивую ограниченную страницу, только активные продукты с активными вариантами. Поиск: название модели, бренд, SKU активного варианта, slug тега. Фильтры slug комбинируются через AND, неизвестные дают пустую страницу. Не ищем текст по ключам переводов. Limit 1–100; стабильный порядок pk. Непустая выдача со всеми связями — 4 SQL; пустая может требовать меньше. Варианты без demo-остатка видны, но недоступны.

## Независимый движок

`from codex_ecommerce.catalog import Variant, Gallery, VariantSelector`

Передать снимки одного продукта: `VariantSelector().select(variants, galleries, color='black', size='M')`. Цена Decimal, доступность явная. DTO неизменяемые, URL галереи — строки, никаких загрузок фотографий. Нет выбора соседнего размера/цвета. Галерея цвета либо общая `color=None`; пустая допустима. Неоднозначные SKU/сочетания, галереи и смешение валют приводят к CatalogSelectionError(code, action). `purchase_allowed` — только eligibility снимка, не резерв и не авторизация оплаты.

## Django adapter и ручная проверка

`CatalogVariantSelection().select(product_slug=..., color=..., size=...)` загружает активный продукт, все его варианты (включая неактивные для явного отказа) и галереи за 3 SQL. Product.DoesNotExist остаётся ответственностью Django, ошибки выбора — движка.

GET `/produkt/manstore-m2223/variante/?color=black&size=M` — JSON preview. XL иллюстративно недоступен; XXXL возвращает 404 с кодом и переведённым сообщением. Не выполнит покупку, резерв, оплату или синхронизацию eBay. Поле `demo_available` не является реальным остатком. Адрес основного preview 8030 требует перезапуска сервера с --noreload для новых routes; для проверки запущен отдельный локальный 8031.

## Подключение витрины 16.10.2026

Главная загружает до 4 активных продуктов через catalog_products (4 SQL с prefetch). ProductDetailView по slug использует тот же набор связей (4 SQL). Проекция presentation.product_presentation переводит ORM в JSON-safe данные, выбирает начальное сочетание через независимый VariantSelector и не выполняет SQL внутри цикла. Начальный размер M при доступности, иначе первый доступный; после действий пользователя не меняем размер/цвет молча.

Постоянный маршрут `catalog:detail` `/produkt/<slug>/`; старый `/produkt/demo/` временно перенаправляет на manstore-m2223. Карточки главной ведут на собственную модель. Пустая БД не заполняется из GET и не выводит выдуманные карточки. Неактивный/неизвестный продукт возвращает 404.

Общий catalog-selection.js обновляет фото/цвет/размер/SKU/цену и проверяет выбор GET-запросом к preview. Во время запроса, ошибки или недоступности CTA выключен. AbortController и sequence guard исключают устаревший ответ; ответ дополнительно сверяется с выбранным цветом/размером. Исходный заголовок модели стабилен, подписи цвета/размера меняются. Фото переключается только на exact/common галерею, при отсутствии фото не подставляется чужой цвет. Перелистывание фотографий остаётся отдельной будущей задачей.

Домашняя кнопка Schnellkauf пока показывает честное уведомление preview вместо ложного добавления в корзину. На PDP действие «Auswahl prüfen» тоже не создаёт корзину/заказ. Остатки и цветовые варианты seed — демонстрационные, реальные фото имеют общую галерею и не доказывают конкретный цвет. Нижние характеристики/рекомендации и size guide сохраняют исходный макет с отметкой demo.

Ограничения: текущая модель количества явно demo. Нет protection от изменения цены/остатка между preview и будущей покупкой — будущий checkout обязан повторно проверить данные транзакционно. Публичного HTTP поиска и рабочей корзины ещё нет. Необязательное отслеживание не подключено; новые cookies, клиентские события наружу и бизнес-записи этим UI не создаются.

Проверки: tests/web/test_catalog_queries.py, test_catalog_variant_adapter.py, test_variant_preview.py, test_catalog_bound_pages.py; tests/engine/test_variant_selection.py. Полный прогон: 106 passed, Ruff/Django check и makemigrations --check успешно. Browser evidence: visuals/catalog-binding (desktop/mobile, JSON). Отдельно проверены быстрые S→L с задержкой старого ответа и отказ сети. 0 JS pageerror, горизонтального overflow на PDP 390px нет; мобильная карточка 315px при ширине ряда 358px сохраняет край следующей.

Visual lint исходного PDP сообщает контраст декоративных разделителей, намеренный truncate рекомендаций и icon-font overflow до загрузки внешнего шрифта; композиция не переделывалась для подавления этих эвристик. Контраст выбранного размера исправлен явно. Tailwind runtime остаётся development, production CSS и локальные шрифты ещё отдельный этап. Это не полная accessibility-приёмка.
