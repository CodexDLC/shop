# HTML-витрина из исходных макетов

Вход: index.html. Django и backend для просмотра не нужны. Для GitHub Pages вход — docs/index.html, публикация из /docs.

30 страниц восстановлены из пользовательских HTML в design-handoff. Соответствие записано в source-map.json. tools/restore_reference_prototype.py проверяет сохранность body: исходные блоки, фотографии, подписи, классы и inline-скрипты сохранены. Прежняя упрощённая версия сохранена в docs/design/archive/replaced-static-prototype.

Общие значения Tailwind подключены через assets/reference-tokens.js; индивидуальные настройки исходных страниц сохранены. assets/reference-navigation.js связывает страницы. Tailwind runtime лежит локально в assets/vendor. Оригинальные Google Fonts, иконки и фотографии остаются внешними ресурсами: для них нужен интернет. Это ещё не автономная offline-сборка и не финальный production CSS.

Основные экраны: главная, каталог, товар, корзина, адрес, проверка оплаты, подтверждение; поиск, пустые состояния, ошибки, авторизация, кабинет, помощь, юридический макет и письма. Мобильные исходники сохранены отдельными HTML с суффиксом -mobile.

Это демонстрация интерфейсов. Исходные локальные интеракции сохранены; наличие кнопки не означает готовую серверную функцию. Реальных регистрации, оплаты, отправки писем и записи в eBay нет. Использовать только вымышленные данные. Условия доставки, возвратов, примерки и прочие обещания из макетов требуют утверждения перед запуском магазина.

При необходимости локального просмотра по HTTP: python -m http.server 8020 --bind 127.0.0.1 --directory docs
Открыть http://127.0.0.1:8020/prototype/. Сервер только раздаёт статические файлы.

Общее обрамление: components/header.html и components/footer.html формируются из главной страницы. При сборке они заменяют только внешние header/footer на страницах витрины; почтовые примеры остаются без изменений. Общие стили обрамления — assets/shared-chrome.css. source-map.json фиксирует проверку оригинала до замены обрамления.
