# Статический HTML-прототип Männermasche

Вход — index.html. Все страницы и assets находятся в этой папке, без Django, CDN и внешних API. Общая тема и навигация: assets/theme.css и app.js; фичи: catalog, checkout, account. Исходные генераторные примеры отдельно в design-handoff.

## Локально

Из корня проекта:

```powershell
python -m http.server 8020 --bind 127.0.0.1 --directory docs
```

Открыть http://127.0.0.1:8020/ — docs/index.html переводит в prototype/index.html. Каталог/search, цвет/размер, demo-cart, адресная валидация, имитация успеха/ошибки, account/service/legal/email preview связаны переходами.

Корзина сохраняется в localStorage данного origin. Временный адрес и receipt — sessionStorage. Вводить только вымышленные данные. Нет настоящей регистрации, подписки, оплаты, отправки писем или eBay. Для новой демонстрации очистить site storage браузера; пароль и реквизиты карт не вводятся.

## GitHub Pages

В настройках репозитория Pages: Deploy from a branch → нужная ветка → /docs. Вход docs/index.html, ресурсы прототипа относительные и работают с project-repository prefix. docs/.nojekyll отключает Jekyll. Другой вариант — содержимое prototype как корень отдельного репозитория, его index.html становится входом; собственный 404 перенести вместе.

Репозиторий не создан и публикация не выполнена этой задачей. Исходники сервера и секреты не входят в docs/prototype. В /docs также остаётся проектная документация: при публикации существующего репозитория она тоже доступна. Если нужна только витрина, использовать отдельный репозиторий с содержимым prototype.

## Дизайн и ограничения

По умолчанию editorial Bodoni/Jakarta, кнопка «Stil A/B» переключает на sans/небольшие скругления с теми же данными и компонентами. Это визуальное сравнение, не окончательное утверждение темы. Шрифты локально с OFL licenses. SVG — демонстрационные изображения; фото производителя подключаются позже.

Пять тестовых товаров, упрощённые фильтры, без настоящих stock rules и persistence сервера. У каждой иллюстрируемой расцветки один снимок; листание дополнительных фото не добавлено. Юридические страницы содержат заглушки. Email hub — браузерный preview, не проверенная совместимость с Outlook/Gmail.

Проверено 14.10.2026: локальные ссылки/assets, 12 страниц на mobile без horizontal overflow/JS errors; category filter → цвет/размер → корзина → адресная валидация → demo payment → receipt. Desktop/mobile screenshots находятся в docs/project/visuals/static-*. После изменений проверки повторять по затронутым сценариям.

Visual lint: пустой alt у декоративных category illustrations принят (имя ссылки задано текстом). Overflow товарного ряда — согласованный горизонтальный scroll, не переполнение страницы.
