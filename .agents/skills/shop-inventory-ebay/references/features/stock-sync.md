# Прямой stock sync

Статус: Запланировано; external writes отсутствуют в коде.

Продажа сайта учитывается локально, исходящее изменение сохраняется устойчиво и подтверждается отдельно. Старый снимок eBay не перезаписывает pending update. События/сверка имеют dedup keys. Полный импорт eBay orders/addresses не входит в scope; минимальные события продаж допустимы при необходимости для корректности. Частота 10 секунд — обсуждённая возможность, не SLA; quota/методы проверяем до настройки.

Включение: read-only/dry-run, пилотные SKU, отдельная авторизация live writes, pause, журнал ошибки и последней успешной сверки. Приёмка: повтор события, timeout с неопределённым исходом, stale read, ручная правка, пропущенное событие. Межплощадочный общий атомарный резерв не обещаем.
