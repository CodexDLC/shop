# Галерея цвета

Статус: выбор набора цвета реализован; PDP миниатюры и native zoom dialog подключены 20.10.2026. Импорт/S3 — отдельные этапы.

Смена цвета переключает главное фото и галерею при наличии снимков этого цвета. Размеры разделяют одну галерею цвета. Если снимков нет — общее фото и явное обозначение цвета, без автоматического перекрашивания. Цена/наличие/доставка относятся к выбранному SKU. Начальный вариант задаётся product_presentation, последующие SKU проверяются variant_preview API; выбор соседнего размера/цвета молча запрещён.

Приёмка: смена цвета без смешивания галерей, смена размера без дублирования фото; на mobile и с клавиатуры выбранный SKU очевиден.

## Мобильная мини-карточка

Выбор цвета меняет весь набор фото и показывает первый снимок нового набора. Горизонтальный жест используется для листания товаров, не фотографий. Переключение отдельных фото отложено, способ ещё не выбран. См. [мобильный ряд](mobile-product-rail.md).


## Реализация PDP

`web.catalog.presentation.product_presentation.initial_gallery` использует prefetched images без нового SQL. `catalog/product.html` → includes/gallery_dialog.html, storefront/product-gallery.js/css: отдельный PDP-компонент с native dialog; миниатюры выбирают кадр, Escape/close возвращают focus, стрелки работают в диалоге. `catalog-selection.js` посылает catalog:gallery для выбранного и подтверждённого набора, кеширует подтверждённые URL только в текущем состоянии страницы. При размере тот же набор не сбрасывает кадр, при цвете выбирается первый. Не пересылать устаревший SSR набор после подтверждения API.

Пустой набор/ошибка изображения — явные состояния с ключами текста, без выдуманных фото. Повторный выбор не загрузившегося URL не должен скрывать ошибку; учитывать initial SSR error до deferred JS. Тесты test_product_gallery.py, test_product_gallery_behavior.py и tests/js/product-gallery.cjs/catalog-gallery-selection.cjs. Реальные фото на текущем devтоваре могут быть единичными; multi-image и ошибки проверяются отдельными fixtures. Не утверждать, что источники импортированы в S3 или внешние ресурсы локализованы. DOM-событие gallery не является разрешением отправки аналитики.
