# Импорт производителя

Статус: Запланировано; фактическая структура архива пока не исследована.

Шеф сортирует фото артикулов eBay, архив оценивается примерно в 30 ГБ PNG. Не требовать пересортировки заранее. Сначала небольшой образец → правила идентификаторов → dry-run → отчёт совпадений/неоднозначностей → подтверждение. Не выводить SKU из случайного похожего имени. Повторный импорт сохраняет ручные привязки, главное фото и порядок; оригиналы не меняются. Производные размеры генерируются в фоне с ограничением ресурсов.

Приёмка: точное и спорное совпадение, повреждённый/слишком большой файл, повтор импорта, ручной порядок после повторного запуска.
