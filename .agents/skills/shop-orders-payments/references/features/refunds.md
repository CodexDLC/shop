# Возвраты

Статус: Запланировано; политика и API не выбраны.

Возврат денег и возвращение товара на склад — разные операции. Суммарный refund не превышает оплаченное за вычетом предыдущих; частичный возврат связан со строками/суммой и provider operation ID. Повтор события не возвращает деньги или запас второй раз. Chargeback не считать обычной отменой заказа.

Приёмка: частичный/повторный refund, race нескольких возвратов, provider timeout, возврат товара без денежного refund. Юридические сроки/правила не выдумывать, брать подтверждённые условия.
