# Структура по фичам

Статус: Правило пользователя для текущей и будущей реализации.

Один класс — один файл, включая модели, формы, DTO и adapters. Если файл требует нескольких классов, заменить его пакетом с отдельными файлами классов; __init__ только экспортирует API. Модуль нескольких функций допустим без классов и при общей ответственности. Не создавать god services и глобальный файл всех models/modal windows. Новая feature reference содержит статус, источник требования, реальные code pointers либо явно планируемые seams, незакрытые решения и проверяемую приёмку. После реализации обновить статус и команды только затронутой фичи.
